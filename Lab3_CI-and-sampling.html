Part 1: Calculating statewide confidence intervals for Washington’s precipitation

In the first part of this lab, you’ll determine a confidence interval for Washington’s precipitation for these two time periods. This can be helpful in identifying whether precipitation has changed across the state (e.g., whether the two confidence intervals overlap) using the county data as your sample.

Task 1 Load the data and filter it to just include data for the state of Washington. Then create a table showing mean precipitation, standard deviation, number of observations (sample size), and upper/lower confidence interval bounds for each of the two time periods in the time_range field. Use kable to display the table when you are done.

washington1950 <- era5_data %>%
  filter(st_name == "Washington", time_range == "1950-69")

washington2005 <- era5_data %>%
  filter(st_name == "Washington", time_range == "2005-24")

washington_stats <- washington1950 %>%
  summarize(mean_precip = mean(prcp_m), sd_precip = sd(prcp_m), n = n()) %>%
  mutate(time_range = "1950-69") %>%
  bind_rows(
    washington2005 %>%
  summarize(mean_precip = mean(prcp_m), sd_precip = sd(prcp_m), n = n()) %>%
  mutate(time_range = "2005-24")
  )

washington_stats <- washington_stats %>%
  mutate(lower_CI = mean_precip - ((sd_precip/sqrt(n)) * qnorm(0.975))) %>%
  mutate(upper_CI = mean_precip + ((sd_precip/sqrt(n)) * qnorm(0.975)))

washington_stats <- washington_stats %>% relocate(time_range)

Task 6: Compare the size of the error terms for your county level data to the error terms at state level that you calculated in Task 1. Are they bigger or smaller? Explain why the formula you used for calculating the error terms produced error terms of different sizes. How is this difference visible in your ggplot graphs?

Counties in Washington that experienced a higher sample mean had a larger confidence interval compared to the counties that had a smaller sample mean. This could be due to the data being more varied since each county had the same sample size. Compared to the state’s summary statistics, the county data still had a greater interval with the smallest interval having a mean of 0.0377 and a lower confidence interval of 0.0311 and upper confidence interval of 0.0445. This could also be attributed to the sample size as each county had 20 observations while the state had 780 observations. The formula for standard error divides the standard deviation by the sample size, so the standard error can either be affected by variation in the data or the size of the data. Since the counties shared the same sample size, the difference in the margin of errors between the counties is more likely due to some counties having more variation in their data. On the other hand, since the difference in the sample size was so drastic between the counties and state data, the difference in the margin of error is more likely due to the sample size. The difference can be seen on the graph by the long horizontal lines that stretch out from the point. While the lines in the state graph are somewhat long, the interval for the x-axis is much smaller on the state level graph than the x-axis on the counties graph.
